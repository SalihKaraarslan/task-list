# Task List App

A simple task list built as a full-stack take-home assignment: a React Native (Expo) mobile app
talking to a Node.js / Express / GraphQL backend backed by MongoDB.

## Project structure

- `backend/` — Node.js + Express + Apollo Server (GraphQL) + Mongoose (MongoDB)
- `mobile/` — React Native app built with Expo, Redux Toolkit and RTK Query

Work in progress. Setup instructions, the GraphQL API reference and design notes will be added as
the project is built.
